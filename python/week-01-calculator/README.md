# Python Calculator

An interactive calculator built with Python as part of my weekly programming practice.

## Features

- Addition, subtraction, multiplication and division.
- Input validation using `try/except`.
- Division-by-zero protection.
- Repeated calculations using `while`.
- Exit by entering `q`.

## Concepts Practiced

- Variables and data types
- `if`, `elif` and `else`
- `while True` and `break`
- `try/except`
- String methods such as `.lower()`
- Input validation

## How to Run

Make sure Python is installed, then run:

```bash
python calculator.py
```

On some systems, you may need to use `python3` instead.
